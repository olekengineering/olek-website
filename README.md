# OLEK Engineering Website

This is the first static website version for olek.lk.

## Files
- index.html
- styles.css
- script.js
- assets/olek-logo.jpg
- assets/project-categories.png

## How to preview
Open `index.html` in any browser.

## How to publish later
1. Create a GitHub account.
2. Create a repository called `olek-website`.
3. Upload all files in this folder.
4. Connect the repository to Cloudflare Pages.
5. Connect the custom domain `olek.lk`.

The contact form sends the enquiry through WhatsApp, so no paid server is required.
